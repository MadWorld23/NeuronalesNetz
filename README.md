# Farbklassifikation mit Logistischer Regression

## Beschreibung
Dieses Projekt implementiert ein einfaches Machine-Learning-Modell zur Klassifikation von Farben anhand von RGB-Werten.

Das Modell wird mit einer CSV-Datei trainiert und kann anschließend Farben einer bestimmten Kategorie zuordnen (z. B. Rot, Grün, Blau).

Es handelt sich dabei um eine **logistische Regression** und nicht um ein vollständiges neuronales Netz.

---

## Verwendete Technologien
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- tkinter



---

## Datensatz
Die Datei `rgb.csv` enthält die Trainingsdaten mit RGB-Werten und den dazugehörigen Labels.


---

## Funktionsweise
1. Laden der CSV-Datei  
2. Aufteilen der Daten in Trainings- und Testdaten  
3. Training des Modells mit Gradient Descent  
4. Vorhersage von Klassen  
5. Auswertung mit einer Confusion Matrix
